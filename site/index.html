Quickly get big files.
Over HTTP or peer-to-peer.

qget (quickly get) is a Rust downloader for the files that take hours: AI model weights, blockchain node snapshots, datasets and disk images. It downloads over many parallel connections, survives crashes, verifies checksums as it goes, extracts archives as they arrive with no 2× disk space, and sends files straight between machines over QUIC.

$curl -fsSL https://qget.dharrsan.com/install.sh | sh

Installs to ~/.local/bin without sudo and checks the SHA-256. Prefer your package manager? Signed apt / dnf / pacman repos below.

Three ways to quickly get

One binary. Every big download.

Use one, or all three at once: a snapshot can come from an HTTP mirror and a peer simultaneously, every byte checked against the same hash.

01 · HTTP

Parallel downloads that don't break

Many adaptive range connections instead of one, so per-connection speed caps on CDNs, S3 and R2 stop mattering.

  • Slow connections split or hedged automatically
  • Crash-safe resume: kill -9, reboot, re-run
  • SHA-256/512 or BLAKE3 verified while downloading
  • Detects files that change mid-download
$ qget --checksum sha256:… https://huggingface.co/…/model.safetensors
NO 2× DISK
02 · STREAM-EXTRACT

Download and extract at the same time

Archives unpack as they arrive and are never stored, so you need room for the extracted data only, not archive plus data. It's ready the moment the download ends.

  • .tar .lz4 .zst .gz .xz
  • Parallel LZ4 and zstd decoding
  • Installed only after the checksum matches
  • Safe against hostile archives
$ qget -x /data/node https://…/snapshot.tar.lz4
03 · PEER-TO-PEER

Machine to machine over QUIC

Send a file or folder directly, through home and office NATs with hole punching, and a relay only as a fallback. Short codes or tickets.

  • Every MiB verified against a BLAKE3 root
  • Pull from several peers and HTTP mirrors at once
  • Resumable, encrypted end to end
  • QUIC via iroh; plain URLs use parallel HTTP/1.1 (HTTP/2 optional)
$ qget yeet ./model.gguf  →  qget yoink 4217-maple-orbit-canyon
Built in Rust

Fast, and correct by design.

  • Memory-safe Rust end to end: no garbage collector and no runtime, just one small binary.
  • A deterministic scheduler: a pure state machine with no I/O, so any download can be replayed decision by decision (--trace, qget replay).
  • Simulation-tested against thousands of seeded fake networks with throttling, stalls and failures, plus 100,000 seeds nightly.
  • Crash-tested: CI kills qget with SIGKILL at random moments and requires a byte-exact result.
  • A library first: the qget crate powers the CLI and can be embedded in your own tools.

Install

One command away.

Signed packages for the major Linux distributions. Add the repository once, and updates arrive with your normal system upgrades.

  1. $sudo curl -fsSLo /etc/apt/keyrings/qget.asc https://qget.dharrsan.com/key.asc

    Saves the qget signing key where apt looks for repository keys.

  2. $echo "deb [signed-by=/etc/apt/keyrings/qget.asc] https://qget.dharrsan.com/apt stable main" | sudo tee /etc/apt/sources.list.d/qget.list

    Adds the repository and only accepts packages signed by that key.

  3. $sudo apt update && sudo apt install qget

    Installs qget. Future versions come with apt upgrade.

  1. $sudo curl -fsSLo /etc/yum.repos.d/qget.repo https://qget.dharrsan.com/rpm/qget.repo

    Adds the repository definition, including where to fetch the signing key.

  2. $sudo dnf install qget

    Installs qget. dnf asks you to confirm the key fingerprint once. Updates come with dnf upgrade.

  1. $curl -fsSL https://qget.dharrsan.com/key.asc | sudo pacman-key --add -

    Adds the qget signing key to pacman's keyring.

  2. $sudo pacman-key --lsign-key {{FINGERPRINT}}

    Marks the key as trusted for packages.

  3. $printf '\n[qget]\nServer = https://qget.dharrsan.com/arch/$arch\n' | sudo tee -a /etc/pacman.conf

    Adds the [qget] repository to pacman.

  4. $sudo pacman -Syu qget

    Installs qget (yay -S qget works too). Updates come with pacman -Syu.

  1. $curl -fsSL https://qget.dharrsan.com/install.sh | sh

    Detects your OS and CPU, verifies the SHA-256, and installs to ~/.local/bin without sudo. Works on macOS (Apple Silicon and Intel) and any Linux with glibc 2.34+.

  2. $cargo install --git https://github.com/dharrsan-hq/qget qget-cli -F p2p

    Or build from source with Rust.

Every package includes peer-to-peer, the man page (man qget) and bash/zsh/fish completions. Packages are installed and tested on Debian 12, Ubuntu 22.04 & 24.04, Fedora and Arch before each release.

Benchmarks

Measured, not promised.

Every output verified by SHA-256. Including the case where qget isn't the fastest yet.

Download and extract a 387 MiB .tar.lz4 (server caps each connection at 25 MB/s)

qget -x4.8 s
aria2c -x16, then tar7.9 s
curl | lz4 -d | tar -x16.4 s

Plain download, 1 GiB (25 MB/s per connection)

aria2c -x16 -s162.7 s
qget4.1 s
curl / wget43 s

Shorter is better. Loopback with server-side per-connection limits; 3 runs, median. For plain downloads aria2c is currently faster, and qget's connection ramp-up is being tuned. Harness and raw results: bench/.
