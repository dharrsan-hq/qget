qget is now one command away on every supported system.

## Install

| System | Command |
|---|---|
| Any Linux or macOS | `curl -fsSL https://github.com/dharrsan-hq/qget/releases/latest/download/install.sh \| sh` |
| macOS / Linux (Homebrew) | `brew install dharrsan-hq/qget/qget` |
| Debian / Ubuntu | `sudo apt install ./qget_0.2.0-1_amd64.deb` |
| Fedora / RHEL | `sudo dnf install ./qget-0.2.0-1.x86_64.rpm` |
| Arch / CachyOS / Manjaro | `sudo pacman -U ./qget-0.2.0-1-x86_64.pkg.tar.zst` |

`install.sh` detects your OS and CPU, downloads the matching archive, **verifies its SHA-256 checksum**, and installs `qget`, its man page and shell completions under `~/.local` without sudo. Use `--dir` to pick another location or `--version` to pin a release.

## What's new

- **Linux packages on every release.** `.deb`, `.rpm` and Arch `.pkg.tar.zst` for x86_64 and arm64. They install the binary to `/usr/bin`, the man page, and bash/zsh/fish completions in each distro's standard locations. CI installs the `.deb` and runs it before anything is published.
- **Homebrew tap.** `brew install dharrsan-hq/qget/qget` works on macOS (Apple Silicon and Intel) and Linux. The formula is regenerated and tested with `brew test` on every release.
- **Wider Linux compatibility.** Binaries are now built against glibc 2.35, so they run on Debian 12+, Ubuntu 22.04+, Fedora 36+ and Arch. v0.1.x required glibc 2.39.

Every binary and package includes peer-to-peer (`qget yeet` / `qget yoink`).

## Verify

```sh
sha256sum -c SHA256SUMS --ignore-missing          # macOS: shasum -a 256 -c SHA256SUMS --ignore-missing
gh attestation verify qget_0.2.0-1_amd64.deb -R dharrsan-hq/qget
```

## Known issues

- **Rare connection collapse.** In about 1 in 100,000 simulated downloads, the connection count can drop to 1 and the download slows to a crawl without failing. If you see a download suddenly using a single connection, press Ctrl+C and re-run the same command; it resumes.
- Plain downloads are still slower than aria2c on fast links.
- Packages are downloads, not repositories yet: updates mean installing the new package. Signed apt/dnf/pacman repositories are planned next. The AUR is pending, because Arch has new-account registration closed.
- Windows is not supported.
