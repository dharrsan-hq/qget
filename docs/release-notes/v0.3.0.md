qget now has **signed package repositories** and a website: **https://qget.dharrsan.com**

Add the repository once, then install and update qget with your normal package manager.

## Install

**Debian / Ubuntu**

```sh
sudo curl --create-dirs -fsSLo /etc/apt/keyrings/qget.asc https://qget.dharrsan.com/key.asc
echo "deb [signed-by=/etc/apt/keyrings/qget.asc] https://qget.dharrsan.com/apt stable main" | sudo tee /etc/apt/sources.list.d/qget.list
sudo apt update && sudo apt install qget
```

**Fedora / RHEL 9+**

```sh
sudo curl -fsSLo /etc/yum.repos.d/qget.repo https://qget.dharrsan.com/rpm/qget.repo
sudo dnf install qget
```

**Arch / CachyOS / Manjaro**

```sh
curl -fsSL https://qget.dharrsan.com/key.asc | sudo pacman-key --add /dev/stdin
sudo pacman-key --lsign-key A03F3628DC0F7B4A2E9AE313AB43FFC72673B3AA
printf '\n[qget]\nServer = https://qget.dharrsan.com/arch/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu qget
```

**macOS / any Linux without root:** `curl -fsSL https://qget.dharrsan.com/install.sh | sh`

## What's new

- **Signed apt, dnf and pacman repositories.** After the one-time setup, `apt upgrade`, `dnf upgrade` and `pacman -Syu` keep qget current. x86_64 and arm64.
- **Everything is signed** with the qget Ed25519 key:
  `A03F 3628 DC0F 7B4A 2E9A  E313 AB43 FFC7 2673 B3AA`.
  Your package manager rejects any package or index not signed by it, even if the website itself were compromised. CI is pinned to this fingerprint and refuses to sign with anything else.
- **Tested from the live site.** After each release is deployed, CI adds the repository and installs qget on Debian 12, Ubuntu 22.04 and 24.04, Fedora and Arch (and arm64 Debian and Fedora), using the exact commands above.
- **Website** with install instructions, benchmarks and how to verify.
- **Open to contributions and criticism**: issues, dharrsan.work@gmail.com or LinkedIn. `AGENTS.md` describes the rules for contributors and their AI assistants.

## Known issues

- **Rare connection collapse** (about 1 in 100,000 simulated downloads): the connection count can drop to 1. Press Ctrl+C and re-run the same command to resume.
- Plain downloads are still slower than aria2c on fast links.
- Windows is not supported.
