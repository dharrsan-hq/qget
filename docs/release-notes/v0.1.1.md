Bug-fix pre-release. Every platform now has a peer-to-peer build.

## Fixes

- **Peer-to-peer on every platform.** v0.1.0 shipped P2P (`qget yeet` / `qget yoink`) only in the Linux x86_64 `-p2p` archive. Linux arm64 and macOS (Apple Silicon and Intel) now have `-p2p` archives too.
- **Clear errors for things that aren't URLs.** In a build without P2P, `qget yoink qget1…` used to fail with `builder error: relative URL without a base`. It now explains that the command needs a `-p2p` build. Any other non-http(s) argument gets "is not a URL" or "unsupported URL scheme" (exit 2).
- **No more automatic HDD mode.** qget switched to HDD tuning (larger blocks, at most 8 connections) whenever the output disk reported itself as rotational. Virtual machine and cloud disks commonly do, so on those machines qget was capped at 8 connections and small files downloaded over a single connection. HDD tuning is now opt-in with `--hdd`.

## Downloads

| File | Platform |
|---|---|
| `qget-v0.1.1-linux-x86_64.tar.gz` / `-p2p` | Linux x86_64 |
| `qget-v0.1.1-linux-aarch64.tar.gz` / `-p2p` | Linux arm64 |
| `qget-v0.1.1-macos-aarch64.tar.gz` / `-p2p` | macOS Apple Silicon |
| `qget-v0.1.1-macos-x86_64.tar.gz` / `-p2p` | macOS Intel (cross-compiled; not executed in CI) |

The `-p2p` archives add `qget yeet`, `qget yoink` and `qget mailbox`. Each archive contains the binary, a man page and bash/zsh/fish completions.

```sh
sha256sum -c qget-v0.1.1-linux-x86_64-p2p.tar.gz.sha256     # macOS: shasum -a 256 -c …
gh attestation verify qget-v0.1.1-linux-x86_64-p2p.tar.gz -R dharrsan-hq/qget
```

On macOS, binaries downloaded with a browser are quarantined by Gatekeeper. Clear it with `xattr -d com.apple.quarantine ./qget`, or download with `curl`.

## Still known

Plain downloads are still slower than aria2c on fast links (connection ramp-up, `fdatasync` stalls in the write path, gaps between blocks). That's the focus of the next release. Windows is not supported. See the [v0.1.0 notes](https://github.com/dharrsan-hq/qget/releases/tag/v0.1.0) for the full feature list and limitations.
