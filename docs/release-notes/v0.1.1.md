Patch pre-release. Every release binary now includes peer-to-peer.

## Fixes

- **Peer-to-peer on every platform.** In v0.1.0 only the Linux x86_64 `-p2p` archive had `qget yeet` / `qget yoink` / `qget mailbox`. There is now **one archive per platform, and every one includes P2P**. No more choosing between a plain and a `-p2p` archive.
- **Clear errors for arguments that aren't URLs.** A build without P2P used to answer `qget yoink qget1…` with `builder error: relative URL without a base`. It now says the command needs P2P support and where to get it. Any other non-http(s) argument gets "is not a URL" or "unsupported URL scheme" (exit 2).
- **No more automatic HDD mode.** qget switched to HDD tuning (larger blocks, at most 8 connections) whenever the output disk reported itself as rotational. Virtual machine and cloud disks commonly do, so on those machines downloads were capped at 8 connections and small files used a single connection. HDD tuning is now opt-in with `--hdd`.

Each archive contains the `qget` binary (HTTP, extraction and peer-to-peer), a man page and bash/zsh/fish completions.

```sh
sha256sum -c qget-v0.1.1-linux-x86_64.tar.gz.sha256     # macOS: shasum -a 256 -c …
gh attestation verify qget-v0.1.1-linux-x86_64.tar.gz -R dharrsan-hq/qget
```

On macOS, binaries downloaded with a browser are quarantined by Gatekeeper. Clear it with `xattr -d com.apple.quarantine ./qget`, or download with `curl`.

## Known issues

- **Rare connection collapse.** Our nightly simulation found a scheduler case, about 1 in 100,000 simulated downloads, where the connection count drops to 1 and the download slows to a crawl without failing. If a download suddenly slows to a single connection, stop it (Ctrl+C) and re-run the same command: it resumes from where it stopped. A fix is planned for the next release.
- Plain downloads are still slower than aria2c on fast links (connection ramp-up, `fdatasync` stalls in the write path, gaps between blocks).
- Windows is not supported. Distribution packages (pacman repo, `.deb`/`.rpm`, Homebrew) are planned for the next feature release.
